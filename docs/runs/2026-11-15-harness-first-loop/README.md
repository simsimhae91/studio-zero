# 다시 앉힌 하네스의 첫 실제 실행 (2026-11-15)

설계는 `docs/superpowers/specs/2026-11-15-harness-reseated-design.md`. 만든 것은 `packages/eyes`(`sz-eyes`)와 `plugin/`(스킬 `sz:work`, `sz:onboard`, `sz:verify`, 에이전트 `sz:verifier`, 훅 셋). 아래는 만든 날 소유자의 Mac에서 돌린 것이다.

## 1. 검증자만: 한판의 가입 전 첫 화면

주장 다섯 개의 계약을 쓰고 얼린 뒤, 의견 없이 검증자(Opus 서브에이전트)에게 넘겼다. 주장 하나는 일부러 틀리게 적었다("끼니 셋이면 60점". 실제는 30점).

| 주장 | 판정 | 결정한 사실 |
|---|---|---|
| 끼니 하나를 누르면 10점 | 증명 | 0에서 10, 다시 누르면 0. 세 타일 각각 |
| 끼니 셋이면 60점 | 반증 | 30에서 멈춤. 10초를 기다려도 60은 나오지 않음 |
| 로그인 화면으로 간다 | 증명 | 입력, 빈 채 제출의 오류 문구, 뒤로 갔다 다시 들어가기 |
| 폰에서 밀리지 않고 44px 이상 | 증명 | 393px에 더해 375, 360, 320px |
| 누르는 느낌이 좋다 | 확인 못 함 | 소유자의 몫. 영상을 남김 |

8분 42초, 11.6만 토큰. 계약에 없던 것 둘을 적었다: 겨루기 카드의 '나' 점수가 첫 끼니에는 움직이지 않는다(62, 62, 72, 82). 비밀번호 칸의 초점 외곽선이 둥근 테두리 밖에 네모로 그려진다. 그리고 `sz-eyes` 자신의 결함 하나: 컨트롤을 선택자로 물어서, 라우터가 겹쳐 둔 두 화면 가운데 밑의 것이 대답했다(로그인 화면에 첫 화면의 버튼이 있다고 하고 자기 버튼은 빠뜨림). 컨트롤을 그려진 자리에서 묻도록 고쳤다.

제품 코드에 표식은 필요 없었다: 화면의 글자로 누른다.

## 2. 플러그인으로 처음부터 끝까지: 더치페이 계산기

빈 폴더에서 `claude -p --plugin-dir plugin --model opus`로 세션 하나를 띄우고 요청 한 문단을 줬다. 사람은 끼어들지 않았다.

- 지도(`.sz/map.md`)를 쓰고, 레인 M으로 잡고, 주장 여섯 개의 계약을 썼다. 주장은 숫자까지 적혔다("35,000원/3명이면 11,700원, 35,100원, 100원"). 위험 둘을 먼저 적었다(부동소수점, 쉼표 붙여넣기).
- `index.html` 하나(7.7KB)를 만들었다.
- 검증자가 결함을 찾았다: `12345.6`을 넣으면 소수점이 무시되고 숫자가 이어져 123,456원이 된다(10배). 15자리를 붙여 넣으면 칸에서 잘린다.
- 만든 쪽이 고쳤고, 검증자가 고친 파일(해시로 구분)에서 처음부터 다시 확인했다.
- 다섯 주장 증명, 하나("폰에서 쓰기 편한가")는 소유자의 몫으로 남김. 남긴 것도 말했다(10자리 넘는 총액의 줄바꿈).
- 띄운 서버는 껐고, 진행 기록에 한 줄을 남겼다.

14분 42초. 증거 한 장은 2.9MB.

## 3. iOS: credeal의 자기 흐름

`sz-eyes ios spare`로 전용 시뮬레이터를 만들고, credeal의 이미 빌드된 앱을 깔고, credeal 자신의 `e2e/tour-tabs.yaml`을 `sz-eyes ios flow`로 돌렸다: 58단계 전부 통과, 107초, 토큰 0. 화면 8장과 필름, 영상이 증거 폴더에 남았다.

그 흐름 파일은 스크린샷을 소유자 체크아웃의 절대 경로에 쓰게 되어 있다. 같은 날 앞서 손으로 돌렸을 때 그 폴더의 8장이 덮어써졌다(되돌릴 수 없었고, 소유자에게 말했다). `sz-eyes`는 흐름을 복사본에서 돌리며 절대 경로를 증거 폴더로 옮긴다: 이번 실행 뒤 그 폴더의 파일 시각은 그대로였다.

끝난 뒤 시뮬레이터를 지우고, Metro를 끄고, clone을 지웠다.

## 실제로 돌려서야 나온 것

1. **디스크.** 이 Mac의 여유는 5GB쯤이었고, 시뮬레이터의 첫 부팅은 3GB쯤 쓴다. 시뮬레이터 둘과 임시 clone으로 118MB까지 내려갔다. 스킬과 검증자의 지시에 "부팅 전에 여유를 보고, 끝나면 지운다"를 넣었다.
2. **검증자는 기본으로 영어로 적는다.** 증거를 읽는 사람은 소유자다. 계약의 언어로 적도록 했다(2번 실행에서는 한국어로 나왔다).
3. **멈춘 화면만 찍어야 한다.** 누른 직후의 화면에는 올라가는 중인 숫자가 찍혔다(문구는 10점인데 숫자는 9). 연속 두 장이 같아질 때까지 기다린다.
4. **검증자가 눈에 띈 것을 둘 곳이 없었다.** `sz-eyes contract notice`와 증거 페이지의 한 구획을 만들었다.

## 확인하지 않은 것

- L 레인(여러 마일스톤, 소유자에게 먼저 묻기)은 돌리지 않았다.
- 훅 셋은 손으로 입력을 넣어 확인했다. 2번 실행에서 세션 시작 안내는 확인됐지만, 얼린 파일 보호와 멈춤 알림이 실제 세션에서 걸린 것은 보지 못했다(걸릴 일이 없었을 수 있다).
- 기존 프로젝트에서 구현이 낀 한 바퀴(이어서 하기)는 아직이다. 1번은 검증만, 2번은 새 프로젝트다.
- 취향(디자인 핸드북)은 아직 새 하네스에 옮기지 않았다. 2번의 화면은 깔끔하지만 어디서나 볼 법한 모양이다.
- Android, Mac, Windows, 게임.
