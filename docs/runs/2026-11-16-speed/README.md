## 읽은 것

- **35분의 대부분은 짓는 에이전트의 생각이다.** 명령이 실제로 도는 시간은 마일스톤당 5~6분이다(소유자: 샌드박스 안 444번 9.4분, 밖 110번 15.7분, 네 마일스톤 합). 나머지는 모델의 턴이다.
- **두 실행의 차이는 추론 강도로 보인다.** 같은 모델, 같은 마일스톤에서 짓는 쪽의 출력이 xhigh는 12.6만~15.5만 토큰, high는 5.5만~9.7만 토큰이고, 시간이 그만큼 갈린다. 판정 결과는 같았다. 한 번씩 돈 값이고 두 실행이 같은 Mac에서 겹쳐 돌았다.
- 처음에 나는 차이를 샌드박스 대응과 자동 모드 덕으로 짐작했다. 틀렸다: 소유자의 세션은 `bypassPermissions`라 샌드박스 밖 호출에 승인 대기가 없었고, 샌드박스에 막혀 다시 한 횟수도 두 실행이 비슷했다(브라우저가 막힌 횟수: 12개 에이전트에 24번, 10개 에이전트에 16번).
- **그래프는 켜지지 않았다.** 계획이 남은 셋을 한 줄로 두었고 까닭을 적었다: "m4는 m3에서 만드는 주소 상태 형식이 있어야 하고, m5는 public/index.html·style.css·app.js에서 m3·m4와 같은 줄을 고친다. 그래서 나란히 지을 수 있는 조합이 없다." 화면 파일이 셋뿐인 한 페이지 제품에서는 맞는 판단이다. 내가 "남은 셋은 독립으로 보인다"고 한 것이 틀렸다. 나란히 짓는 길은 실제로는 아직 한 번도 돌지 않았다.
- 샌드박스를 켠 채 자동 모드로 워크플로가 끝까지 돌았다(막혀서 멈춘 곳 없음). 다만 에이전트마다 한두 번은 여전히 샌드박스 안에서 먼저 눈을 불렀다: 세션이 샌드박스 안이라는 것을 워크플로가 모든 에이전트에게 처음부터 말해 주지 않는다.
- 워크플로가 돌려준 결과가 앞 실행에서 닫힌 마일스톤의 약속을 전부 "증명"으로 적었다(m1의 주인 판단 하나는 디스크에 확인 못 함). 보고하던 세션이 디스크와 대조해 잡았다.

## 덧붙임: Sonnet xhigh는 Opus high보다 빠른가

소유자: "sonnet xhigh vs opus high는 뭐가 더 빠를까?", "마일스톤 하나만 넣어봅시다." 같은 시작 커밋(`1c4925b`)에서 m3-share 하나를, 짓는 쪽만 Sonnet 5.5 xhigh로 돌렸다(`claude -p --model sonnet --effort xhigh`, 샌드박스 켬, 자동 모드). 검증자는 플러그인이 Opus로 고정하고 있고 강도는 앞 실행과 맞춰 high로 주었다(`args.effort = { verify: "high" }`: 강도를 단계별로 주는 장치가 실제로 돈 첫 실행). 전체 35분 37초.

같은 m3, 세 실행:

| | Opus xhigh (소유자) | Opus high | Sonnet xhigh |
|---|---|---|---|
| 계획 | (처음부터 지은 실행이라 견줄 수 없음) | 1.2분 | 5.9분, 출력 4.2만 토큰 |
| 짓기 | 23.2분, 71턴, 출력 12.6만 | **11.3분, 44턴, 5.7만** | 21.0분, 64턴, 13.2만 |
| 검증 | 9.1분 | 5.1분 | 7.2분 (Opus high) |
| 닫기 | 0.9분 | 0.9분 | 약 0.7분 |
| 약속 | 6개 증명 | 6개 증명 | 7개 증명 |
| 반증 / 고침 | 0 / 0 | 0 / 0 | 0 / 0 |
| 검증자가 계약 밖에서 본 것 | 4 | 2 | 4 |
| 제품 코드에 더한 줄 | (재지 않음) | 779 | 1,321 |

- **Sonnet xhigh는 Opus high보다 느렸다.** 짓기가 거의 두 배이고 Opus xhigh와 비슷하다. 출력량도 Opus xhigh만큼이다: 걸리는 시간을 정하는 것은 모델보다 추론 강도였다.
- 계획도 길었다: Sonnet xhigh 계획자는 이어 하는 실행인데도 m3의 명세를 다시 풀어 쓰고 약속을 일곱 개로 잡았다.
- 세 실행 모두 한 번에 검증을 통과했다. 이 마일스톤에서는 짓는 쪽이 약해서 고치기가 붙는 일은 없었다.
- 코드는 Sonnet xhigh가 70% 더 많이 썼다. 더 많이 쓴 것이 더 나은 것인지는 재지 않았다.
- 한 번씩 돈 값이다.

3. 고칠 것: 샌드박스 안이라는 것을 모든 에이전트에게 처음부터 알림; 앞 실행에서 닫힌 마일스톤의 판정을 지어내지 않음.
