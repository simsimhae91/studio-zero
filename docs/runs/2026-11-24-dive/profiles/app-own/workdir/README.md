# 랠리판 (RallyPan)

배드민턴 클럽용 복식 대진표 앱. 출석 체크부터 자동 대진, 코트 현황, 경기 기록, 회비 체크까지 클럽 운영을 폰 하나로.

- Android: Google Play "랠리판 - 배드민턴 클럽 대진표" (v1.3.2)
- iOS: App Store "랠리판" (v1.3.2)
- 사용 중인 클럽: 영통 수요셔틀(수원), 광교 새벽콕(수원), 동백 화목클럽(용인) — 회원 약 110명

> 원래 우리 클럽(영통 수요셔틀) 쓰려고 만든 앱입니다. 다른 클럽에서도 쓰실 수 있게 공개해 뒀어요.

## 주요 기능

| 화면 | 하는 일 |
| --- | --- |
| 회원 | 회원 등록, 급수(A/B/C/D/초심), 성별, 연락처. 운영진 권한(회장/총무) 지정 |
| 출석 | 클럽 날 입구에 QR 코드를 띄우면 회원이 자기 폰으로 찍어 출석 |
| 자동 대진 | 출석한 회원으로 복식 대진 생성. 모드 2가지 (아래) |
| 코트 현황판 | 코트별 진행 중 경기, 경기 종료 버튼, 다음 대진 배정 |
| 경기 기록 | 점수 입력, 회원별 경기 수·승패 누적 (운영진만 열람) |
| 회비 | 월 회비 납부 체크, 미납자 목록 |

### 자동 대진 모드

- **랜덤**: 대기 중인 회원 중 4명을 무작위로 뽑아 2:2로 나눕니다.
- **급수 균형** (기본): 4명을 뽑은 뒤 양 팀 급수 점수 합(A=5 … 초심=1)이 가장 비슷하게 나눕니다.
  - `같은 급수끼리` 옵션 (기본 켜짐): 4명을 같은 급수 그룹 안에서만 뽑습니다. 그룹에 4명이 안 되면 그 그룹은 다음 배정 때 다시 시도합니다.
  - 같은 날 같은 파트너가 두 번 묶이지 않게 피합니다.

대진은 코트가 빌 때(경기 종료 버튼) 한 판씩 생성됩니다.

## 기술 스택

- Flutter 3.24 / Dart 3.5
- Firebase Authentication (카카오 로그인 연동, 커스텀 토큰)
- Cloud Firestore (실시간 동기화: 코트 현황판을 여러 폰에서 같이 봄)
- Firebase Cloud Functions (Node 20): 카카오 토큰 교환, 월 회비 알림
- Firebase Cloud Messaging: 대진 배정 알림

## 폴더 구조

```
lib/
  main.dart
  app/            # 라우팅, 테마
  features/
    members/      # 회원, 급수
    attendance/   # QR 출석
    matchmaking/  # 대진 생성 (matchmaker.dart)
    courts/       # 코트 현황판
    records/      # 경기 기록, 통계
    dues/         # 회비
  data/           # Firestore 리포지토리
functions/        # Cloud Functions (TypeScript)
test/
```

## 개발 환경

```bash
flutter pub get
cp lib/firebase_options.example.dart lib/firebase_options.dart   # 본인 Firebase 프로젝트 값으로 채우기
flutter run
```

카카오 로그인을 쓰려면 `android/app/src/main/AndroidManifest.xml`과 `ios/Runner/Info.plist`에 카카오 네이티브 앱 키를 넣고, `functions/.env`에 `KAKAO_REST_KEY`를 넣으세요.

테스트:

```bash
flutter test
cd functions && npm test
```

## 알려진 문제

- 안드로이드 일부 기종(갤럭시 A 시리즈)에서 대진 알림이 늦게 옴 (FCM 우선순위 확인 중)
- 다크 모드에서 회비 화면 글자 대비가 낮음
- 회원 탈퇴 시 경기 기록이 같이 지워지지 않음
