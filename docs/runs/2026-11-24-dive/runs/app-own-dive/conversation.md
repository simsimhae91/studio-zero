## 세션 (164s)

## 랠리판, 다음에 뭘 할까

**제가 이해한 것**
- 랠리판은 총무님이 만들어 직접 쓰는 앱이고, 지금 세 클럽에서 회원 110명쯤이 씁니다.
- 대진은 코트가 빌 때마다 한 판씩, 급수 균형으로 만들어지고 `같은 급수끼리`가 기본으로 켜져 있습니다. 같은 급수에 4명이 안 모이면 그 급수는 다음 배정 때까지 기다립니다.
- 쓰다가 불편한 데가 있으셨는데, 그게 뭔지는 아직 말씀 안 하셨습니다.

방향 넷을 골라 봤습니다. 기능 하나를 네 가지로 바꾼 게 아니라, **누가 쓰는지, 언제 쓰는지**가 서로 다릅니다.

**1. 내 차례 보이기**: 벤치에서 기다리는 회원용
```
수요일 밤 8시 40분, 당신(C조)은 벤치에서 20분째 기다리는 중.
┌──────────────────────┐
│ 다음 대진  2번째       │
│ 예상       약 10분     │
│ 오늘       2게임 / 평균 3.4 │
│ ▸ 오래 쉰 사람 먼저 들어감 │
└──────────────────────┘
```

**2. 총무 현장 손보기**: 클럽 날 운영진용
```
8시 10분, 3명이 늦게 왔고 1명은 9시에 먼저 간다고 함.
┌ 대기 명단 ─────────────┐
│ 김OO  [쉬는 중] [먼저 감] │
│ 이OO  [늦게 옴 +]        │
│ 박OO ↔ 최OO  같이 안 묶기 │
│ [이 대진 다시 뽑기]       │
└──────────────────────┘
```

**3. 회원이 보는 내 기록**: 클럽 날 다음 날, 일반 회원용
지금 경기 기록은 운영진만 볼 수 있습니다.
```
목요일 점심, 어젯밤 경기를 다시 보는 중.
┌ 11월 ─────────────────┐
│ 14게임 9승  승률 64% ▲   │
│ 제일 잘 맞는 파트너: 정OO │
│ B조까지 남은 것: 4승      │
└──────────────────────┘
```

**4. 와일드카드: 클럽 교류전**
랠리판을 쓰는 영통·광교·동백 세 클럽이 교류전을 여는 날, 서로의 회원을 게스트로 한 번에 받아 섞은 대진을 돌립니다.
```
토요일 오후, 광교 새벽콕 체육관.
[교류전 열기] → 영통 12명 + 광교 15명 출석
대진: 클럽 섞기 ON · 급수 균형 ON
```
