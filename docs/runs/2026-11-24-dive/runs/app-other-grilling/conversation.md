# grilling · app-other

## 주인 (씨앗)

당근으로 물건 팔다 보면 좀 불편한 게 있거든요. 당근에 이런 기능 하나 추가하면 좋겠다 싶은데, 뭘 추가하고 또 뭘 하면 좋을까요?

## 세션 (114s)

그릴링 시작. 당근 판매자 기능이 지금 어디까지 있는지는 백그라운드에서 조사 중. 이미 있는 기능을 다시 제안하는 일은 막을 것. 아래는 지금 바로 정할 수 있는 질문들.

---

❓ **Q1** - **불편한 점이 정확히 뭔가요?**: "좀 불편한 게 있다"고만 하셔서 아직 모름. 이게 결정 트리의 뿌리. 판매자가 흔히 겪는 후보:

- (a) **반복 채팅**: "아직 판매중인가요?", "네고 되나요?", "어디서 거래해요?"에 매번 같은 답을 함
- (b) **노쇼·약속 펑크**: 시간 잡았는데 안 나오거나 연락이 끊김
- (c) **가격 정하기**: 얼마에 올릴지 감이 안 옴
- (d) **등록 귀찮음**: 사진 찍고 글 쓰고, 여러 개 올릴 때 하나하나 반복
- (e) **무리한 네고·비매너 구매자** 대응
- (f) 기타: 직접 겪은 장면 그대로

➡️ 직접 겪은 **구체적인 장면 하나**로 답해 주세요. 예: "지난주 의자 팔 때 같은 질문을 12명한테 받음". 장면이 없으면 (a)를 추천. 판매자가 가장 자주 겪고 측정하기도 쉬움.

---

❓ **Q2** - **이 아이디어로 뭘 하려는 건가요?**: 결과물이 뭐냐에 따라 "또 뭘 하면 좋을까"의 답이 완전히 달라짐.

- (a) **PM/기획 포트폴리오·과제**: 문제 정의 → 근거 → 기능 기획서 → 지표
- (b) **당근에 실제로 제안**: 피드백 채널이나 지원용 제안서
- (c) **직접 만들기**: 확장 프로그램, 별도 도우미 앱 같은 사이드 프로젝트. 단, 당근은 공개 API가 없어서 제약이 큼
- (d) 그냥 생각 정리

➡️ (a) 포트폴리오/기획 문서 추천. 당근 내부 기능은 외부에서 만들 수 없음. 그러니 "기획 + 검증 근거"가 가장 현실적인 결과물.

---

❓ **Q3** - **어떤 판매자 입장인가요?**: 가끔 하나씩 파는 일반 판매자인지, 이사·정리 때문에 여러 개를 한 번에 파는 판매자인지. 같은 불편이라도 해결책이 다름. 예를 들어 반복 채팅이면 일반 판매자에게는 빠른 답장이, 여러 개 파는 판매자에게는 물건별 자동응답이 맞음.

➡️ **가끔 파는 일반 판매자**(본인 경험 기준) 추천. 본인이 직접 겪은 불편이라 근거가 진짜고, 당근 사용자의 대다수이기도 함.

   - **들어가는 사람**: 물어본 사람이 들어온 순서대로 자동으로 줄에 들어감. 판매자는 "줄에서 빼기"로 사라진 사람을 정리할 수 있음.
   - **약속 표시**: 1번 줄에 약속 정보가 같이 보임. 예: `1번 OO님 · 약속 토 3시 문고리` / `2번 △△님 · 대기`
   - **순서 바꾸기**: 기본은 순서대로. 판매자가 다른 사람을 고르면 그 사람이 약속 자리로 올라가고 나머지 순서는 그대로.
   - **차례 넘기기**: 1번이 취소하면 버튼 하나로 2번에게 "차례 왔어요"를 보냄. 2번이 답이 없으면 판매자가 다시 눌러 3번에게 넘김. 2번 줄에는 "답 기다리는 중 · 2시간 전 알림 보냄"처럼 표시.
   - **구매자 화면**: 구매자는 자기 순서만 봄. 예: "현재 3번째예요"
   - **위치**: 판매내역에서 물건을 누르면 나오는 화면.

3. **범위 밖, 또는 확장 계획**
   - **확장 계획**: 자동 예약중, 중복 약속 경고, 예비 약속, 약속 뒤 "거래하셨나요?" 확인, 글로 쓴 약속 감지, 답이 없을 때 자동으로 다음 사람에게 넘기기
   - **범위 밖**: 매너 평가 이의제기, 판매자 전체 일정 겹침, 같은 물건이 여러 개인 글

4. **지표**
   - **핵심**: 채팅이 3개 이상인 물건의 중복 약속률
   - **함께 보는 것**: 같은 물건의 채팅방을 오가는 횟수, 같은 질문에 다시 답하는 비율, 먼저 연락한 사람과 거래가 이뤄진 비율
   - **해치면 안 되는 것**: 거래 완료율, 판매자 응답 속도

5. **리스크**: 줄이 길면 포기하는 구매자가 생길 수 있음. 판매자가 줄 정리를 안 하면 사라진 사람이 앞 순서를 차지함.

6. **근거**

# 당근 "물건별 줄 서기" 한 장 요약

**문제**: 물건 하나에 채팅이 여러 개 오면 누구와 약속했는지, 누가 먼저 물었는지 한눈에 안 보인다. 범보의자(15,000원)에 채팅이 9개 왔고, 채팅방을 오가다 두 사람과 같은 토요일 오후 3시 문고리 거래를 약속했다. 한 명이 헛걸음했고 판매자는 '약속을 안 지켜요' 평가를 받았다. 노쇼가 아니라 판매자가 헷갈린 것이다.

**대상**: 이사나 정리 때문에 한꺼번에 많이 파는 판매자

**기능: 물건별 줄 서기**
- **줄**: 물어본 사람이 들어온 순서대로 자동으로 줄을 선다. 판매자는 "줄에서 빼기"로 정리한다.
- **1번 = 약속**: 1번 자리에 약속 정보가 보인다. 예: `1번 김OO · 약속 토 3:00 문고리`
- **순서**: 기본은 들어온 순서다. 판매자가 다른 사람을 고르면 그 사람이 1번으로 올라가고 나머지 순서는 그대로다.
- **차례 넘기기**: 1번이 취소하면 판매자가 버튼 하나로 2번에게 "차례 왔어요"를 보낸다. 2번이 답이 없으면 다시 눌러 3번에게 넘긴다.
- **구매자 화면**: 자기 순서만 본다. 예: "현재 3번째예요"
- **위치**: 판매내역에서 물건을 누르면 나오는 화면

**지표**
- **핵심**: 채팅이 3개 이상인 물건에서 생긴 중복 약속률
- **함께 보는 것**: 같은 물건의 채팅방을 오간 횟수, 같은 질문에 다시 답한 비율, 먼저 연락한 사람과 거래가 이뤄진 비율
- **해치면 안 되는 것**: 거래 완료율, 판매자 응답 속도

**리스크**: 줄이 길면 구매자가 포기한다. 판매자가 줄을 정리하지 않으면 연락이 끊긴 사람이 앞 순서를 차지한다. 순서를 바꿀 수 있어서 "내가 먼저였는데"라는 불만이 생길 수 있다.

**확장 계획**: 자동 예약중 전환, 중복 약속 경고와 예비 약속, 약속 뒤 "거래하셨나요?" 확인, 채팅에 글로 쓴 약속 감지, 답이 없을 때 자동으로 다음 사람에게 넘기기

**범위 밖**: 매너 평가 이의제기, 판매자 전체 일정 겹침, 같은 물건이 여러 개인 글

**근거**: 당근의 전체 채팅 목록에는 「예약」 표시만 있다. 물건별 채팅 모아 보기, 메모, 라벨은 공개 자료로 확인하지 못했다. 출처는 대부분 간접 자료다.

**할 일**: ① 판매내역에서 범보의자 눌러 보기(1분) ② 이사 판매 경험자 3명 인터뷰

**열린 질문**
1. 판매자 채팅방 안에도 줄 정보를 보여줄까? (추천: 채팅방 위에 "이 분은 줄 2번 · 1번 김OO 토 3시 약속 있음" 한 줄)
2. 답이 없어 건너뛴 2번은 줄 끝으로 보낼까, 줄에서 뺄까?
