---
name: build
description: Run the Studio Zero build workflow with native Codex workers when the owner explicitly requests an unattended build.
---
Read the start questions in the sz:work skill. Ask the owner in the current conversation and keep their answers verbatim. Use asked="away" only when they explicitly ask you to proceed without questions or the run is already unattended. Only the owner may select design="go".

Run the executable bin/sz-codex-build relative to this plugin's root (three directories up from this skill's directory), with the target project as the working directory. Pass one JSON object on stdin with request, asked and answers. Use a quoted heredoc or a file so the user's words stay data. The runner also accepts maxMilestones, side, and an optional Codex model ID. It starts fresh Codex workers and can take as long as the build. Monitor its stage messages, and do nothing else in the project while it runs: no edits, no commits, no records (sz-eyes takes the records of its contracts only from its own workers). If it ends with an error, run it again from the project with the same JSON: it resumes from .sz, keeping contracts, verdicts and commits. Never carry a build on by hand or with agents you spawn: they carry your conversation, so their verdicts are not independent, and sz-eyes refuses them until the runner runs again. On a design stop show the prototype, record the owner's actual verdict with sz-eyes contract judged design feel --verdict yes|no --said "<their words>", and restart with those words. Report stopped, notBuilt, and each evidence page from the result.
